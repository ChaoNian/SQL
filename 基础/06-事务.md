# 06 · 事务
简介
事务 是一组操作的组合,它是一个不可分割的工作单位,事务会把所有的操作作为一个整体一起向系统提交或撤销操作请求,即这些操作要么同时成功,要么同时失败;
默认mysql 的事务时自动提交的,也就是说,当执行一条DML语句,MySQL 会立即隐式的提交事务;

## 目标

理解 ACID 与提交/回滚，能关闭自动提交并演示「扣库存 + 下单」失败回滚；对隔离级别有直觉。

## 大纲
 
### 1. 事务与 ACID

- Atomicity 原子性：事务时不可分割的最小操作单元,要么全成，要么全不成  
- Consistency 一致性：事务完成时,必须使所有的数据都保持一致,约束与业务不变量不被破坏  
- Isolation 隔离性：数据库系统提供的隔离机制,保证事务在不受外部并发操作影响的独立环境下运行,并发事务互不干扰的程度  
- Durability 持久性：事务一旦提交或回滚,它对数据库中的数据的改变就是永久的,提交后不丢

### 2. 基本语法与自动提交

- 开启事务: `START TRANSACTION` / `BEGIN`  
- 提交事务| 回滚事务: `COMMIT`、`ROLLBACK`  
- `autocommit`：会话默认常为开；查/改：`SELECT @@autocommit`  设置: `SET @@autocommit = 0`
- 隐式提交：部分 DDL 会提交当前事务（知晓即可）

### 3. 隔离级别概览

| 级别 | 直觉 | 典型现象（可能） |
|------|------|------------------|
| READ UNCOMMITTED | 能读到别人未提交 | 脏读 | 不可重复读 性能最高,数据安全性最差的 
| READ COMMITTED | 只读已提交 | 不可重复读 |
| REPEATABLE READ | MySQL InnoDB 默认 | 幻读（InnoDB 下多有缓解） |
| SERIALIZABLE | 最强 | 并发下降 |
SERIALIZABLE : 可串行化
注意: 事务隔离级别越高, 数据越安全,但是性能越低;

查看事务隔离级别
SELECT @@ TRANSACTION_ISOLATION;
select @@transaction_isolation;

设置事务隔离级别
SET [SESSION|GLOBAL] TRANSACTION ISOLATION LEVEL {READ UNCOMMITTED | READ COMMITTED | REPEATABLE READ | SERIALIZABLE}
set session transaction isolation level read uncommitted

### 4. 并发事务问题直觉
- 脏读: 一个事务读到另外一个事务还没有提交的数据;
- 不可重复读: 一个事务先后读取同一条记录,但两次读取的数据不同,称之为不可重复读;
- 幻读: 一个事务按照条件查询数据时,没有对应的数据行, 但是插入数据时,又发现这行数据已经存在,好像出现了幻影;  
- 不要求背引擎实现细节（MVCC / 间隙锁留给进阶）

### 5. 实战示例：扣库存 + 下单

- 步骤：开事务 → 检查并扣 `product.stock` → 写 `orders` / `order_item` → 成功则 `COMMIT`，任一步失败 `ROLLBACK`  
- 对比：中途报错若不回滚，可能留下半成品数据

## 示例（占位 · 依赖 demo）

```sql
USE demo;

SET autocommit = 0;

START TRANSACTION;

-- 1) 扣库存（示例 id/数量以种子数据为准）
UPDATE product SET stock = stock - 1 WHERE id = 1 AND stock >= 1;

-- 2) 若 ROW_COUNT() = 0，则库存不足，ROLLBACK
-- 3) 否则 INSERT orders / order_item ...

-- 演示回滚：
ROLLBACK;

SET autocommit = 1;
```

## 小结

- 多步写操作应放进同一事务，用提交/回滚保原子性  
- InnoDB 默认 `REPEATABLE READ`；隔离越高，一般并发越受影响  
- 业务失败要显式 `ROLLBACK`，不要假设客户端断开一定会清干净（视连接与设置而定）

## 常见坑 / 面试点

- DDL 可能导致隐式提交，事务里慎混大规模结构变更  
- 「事务」只对支持事务的引擎有效（InnoDB）；MyISAM 无事务  
- 长事务拖住锁与 undo，宜短小  
- 面试：ACID 含义；四种隔离级别与三种读问题的对应关系
