# 03 · 函数

## 什么是函数

**函数**是指一段可以直接被另外一段程序调用的程序或代码。

## 分类

| 分类 | 说明 |
|------|------|
| **字符串函数** | 对字符串进行拼接、截取、大小写转换、填充等 |
| **数值函数** | 对数值做四舍五入、取整、绝对值等 |
| **日期函数** | 获取当前时间、提取年月日、日期运算与格式化 |
| **流程函数** | 按条件返回不同结果（如 `IF`、`CASE`、`IFNULL`） |

## 1. 字符串函数

MySQL 中内置了很多字符串函数，常用的几个如下：

| 函数 | 功能 |
|------|------|
| `CONCAT(S1, S2, ... Sn)` | 字符串拼接，将 S1, S2, ... Sn 拼接成一个字符串 |
| `LOWER(str)` | 将字符串 str 全部转为小写 |
| `UPPER(str)` | 将字符串 str 全部转为大写 |
| `LPAD(str, n, pad)` | 左填充，用字符串 pad 对 str 的左边进行填充，达到 n 个字符长度 |
| `RPAD(str, n, pad)` | 右填充，用字符串 pad 对 str 的右边进行填充，达到 n 个字符长度 |
| `TRIM(str)` | 去掉字符串头部和尾部的空格 |
| `SUBSTRING(str, start, len)` | 返回字符串 str 从 start 位置起长度为 len 的子串 |

```sql
-- 拼接
SELECT CONCAT('Hello', ' ', 'World');   -- Hello World

-- 大小写
SELECT LOWER('Hello'), UPPER('Hello');  -- hello / HELLO

-- 左右填充（常用于补零）
SELECT LPAD('123', 5, '0');             -- 00123
SELECT RPAD('123', 5, '0');             -- 12300

-- 去空格
SELECT TRIM('  abc  ');                 -- abc

-- 截取（位置从 1 开始）
SELECT SUBSTRING('Hello', 1, 3);        -- Hel

--- 案例
--- 1、由于业务需求变更，企业员工de的工号，统一为5位数 ，目前不足5位数的全部在前面补0，比如：1号员工的工号应该为00001
update emp set workno = lpad(workno, 5)

```

## 2. 数值函数

常见的数值函数如下：

| 函数 | 功能 |
|------|------|
| `CEIL(x)` | 向上取整 |
| `FLOOR(x)` | 向下取整 |
| `MOD(x, y)` | 返回 x/y 的模（余数） |
| `RAND()` | 返回 0~1 内的随机数 |
| `ROUND(x, y)` | 对 x 四舍五入，保留 y 位小数 |

```sql
SELECT CEIL(1.1);          -- 2
SELECT FLOOR(1.9);         -- 1
SELECT MOD(7, 3);          -- 1
SELECT RAND();             -- 0~1 之间的随机数
SELECT ROUND(3.1415, 2);   -- 3.14
```

## 3. 日期函数

常见的日期函数如下：

| 函数 | 功能 |
|------|------|
| `CURDATE()` | 返回当前日期 |
| `CURTIME()` | 返回当前时间 |
| `NOW()` | 返回当前日期和时间 |
| `YEAR(date)` | 获取指定 date 的年份 |
| `MONTH(date)` | 获取指定 date 的月份 |
| `DAY(date)` | 获取指定 date 的日期 |
| `DATE_ADD(date, INTERVAL expr type)` | 返回一个日期/时间值加上一个时间间隔 expr 后的时间值 |
| `DATEDIFF(date1, date2)` | 返回起始时间 date1 和结束时间 date2 之间的天数 |

```sql
SELECT CURDATE();                                    -- 当前日期
SELECT CURTIME();                                    -- 当前时间
SELECT NOW();                                        -- 当前日期时间
SELECT YEAR(NOW()), MONTH(NOW()), DAY(NOW());        -- 年 / 月 / 日
SELECT DATE_ADD(NOW(), INTERVAL 1 DAY);              -- 一天后
SELECT DATEDIFF('2026-12-31', '2026-11-14');         -- 两日期相差天数
```

--- 案例
--- 1、查询所有员工的入职天数，并根据入职天数倒序排序

```sql
SELECT name, DATEDIFF(CURDATE(), entrydate) AS entrydays
FROM emp
ORDER BY entrydays DESC;
```

## 4. 流程函数

流程函数也是很常用的一类函数，可以在 SQL 语句中实现条件判断。

| 函数 | 功能 |
|------|------|
| `IF(value, t, f)` | 如果 value 为 true，则返回 t，否则返回 f |
| `IFNULL(value1, value2)` | 如果 value1 不为空，返回 value1，否则返回 value2 |
| `CASE WHEN [val1] THEN [res1] ... ELSE [default] END` | 如果 val1 为 true，返回 res1，… 否则返回 default |
| `CASE [expr] WHEN [val1] THEN [res1] ... ELSE [default] END` | 如果 expr 的值等于 val1，返回 res1，… 否则返回 default |

```sql
SELECT IF(1 > 0, '是', '否');                    -- 是
SELECT IFNULL(NULL, '默认值');                   -- 默认值

-- 条件式 CASE
SELECT
  CASE
    WHEN score >= 90 THEN '优秀'
    WHEN score >= 60 THEN '及格'
    ELSE '不及格'
  END AS level
FROM exam;

-- 等值式 CASE
SELECT
  CASE gender
    WHEN '1' THEN '男'
    WHEN '2' THEN '女'
    ELSE '未知'
  END AS gender_name
FROM emp;
```

--- 案例
--- 1、查询 emp 表的员工姓名和工作地址（北京/上海 → 一线城市，其他 → 二线城市）

```sql
SELECT
  name,
  CASE workaddress
    WHEN '北京' THEN '一线城市'
    WHEN '上海' THEN '一线城市'
    ELSE '二线城市'
  END AS '工作地址'
FROM emp;
```

--- 2、统计班级各个学员的成绩（≥85 → 优秀，≥60 → 及格，否则 → 不及格）

```sql
SELECT
  name,
  math,
  CASE
    WHEN math >= 85 THEN '优秀'
    WHEN math >= 60 THEN '及格'
    ELSE '不及格'
  END AS '等级'
FROM score;
```

## 5. 聚合函数

- `COUNT(*)` vs `COUNT(列)`（是否计 `NULL`）
- `SUM` / `AVG` / `MAX` / `MIN`
- 与 `GROUP BY` 同用；非聚合列必须进分组（ONLY_FULL_GROUP_BY）

## 示例（占位 · 依赖 demo）

```sql
USE demo;

SELECT
  name,
  UPPER(LEFT(name, 1)) AS initial,
  IFNULL(phone, '未填写') AS phone_show
FROM customer;

SELECT
  DATE_FORMAT(created_at, '%Y-%m') AS ym,
  COUNT(*) AS cnt
FROM orders
GROUP BY DATE_FORMAT(created_at, '%Y-%m');
```

## 小结

- 标量函数作用于单行；聚合函数压缩多行
- 空值用 `IFNULL`/`COALESCE`；分支逻辑用 `CASE`
- 分组查询遵守「选中的非聚合列 ⊆ GROUP BY」

## 常见坑 / 面试点

- `COUNT(列)` 忽略该列的 `NULL`；`COUNT(*)` 计行数
- `LENGTH` 按字节，`CHAR_LENGTH` 按字符（utf8mb4 下易踩坑）
- 在 `WHERE` 对列套函数可能影响索引；可改为对常量做变换
- MySQL 8 默认 `ONLY_FULL_GROUP_BY`，随意 `SELECT` 非分组列会报错
