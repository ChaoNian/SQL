# 03 · 函数

## 目标

会用常用字符串 / 数值 / 日期 / 条件函数，并理解聚合函数与 `GROUP BY` 的配合。

## 大纲

### 1. 字符串函数

- 长度与截取：`LENGTH` / `CHAR_LENGTH`、`SUBSTRING`、`LEFT`/`RIGHT`  
- 拼接与替换：`CONCAT`、`REPLACE`、`TRIM`  
- 大小写：`UPPER` / `LOWER`  
- 查找：`LOCATE` / `INSTR`

### 2. 数值函数

- `ROUND` / `CEIL` / `FLOOR` / `ABS`  
- `MOD`；金额场景优先用 `DECIMAL`，少用浮点

### 3. 日期时间函数

- 当前：`NOW` / `CURDATE` / `CURTIME`  
- 提取：`YEAR` / `MONTH` / `DAY` / `DATE`  
- 运算：`DATE_ADD` / `DATE_SUB` / `DATEDIFF` / `TIMESTAMPDIFF`  
- 格式：`DATE_FORMAT`

### 4. 条件与空值

- `IFNULL(expr, default)`  
- `COALESCE(a, b, ...)`  
- `CASE WHEN ... THEN ... ELSE ... END`  
- `IF(条件, 真值, 假值)`（了解即可）

### 5. 聚合函数

- `COUNT(*)` vs `COUNT(列)`（是否计 `NULL`）  
- `SUM` / `AVG` / `MAX` / `MIN`  
- 与 `GROUP BY` 同用；非聚合列必须进分组（ONLY_FULL_GROUP_BY）

## 示例（占位 · 依赖 demo）

```sql
USE demo;

SELECT
  name,
  UPPER(LEFT(name, 1)) AS initial,
  IFNULL(phone, '未填写') AS phone_show
FROM customer;

SELECT
  DATE_FORMAT(created_at, '%Y-%m') AS ym,
  COUNT(*) AS cnt
FROM orders
GROUP BY DATE_FORMAT(created_at, '%Y-%m');
```

## 小结

- 标量函数作用于单行；聚合函数压缩多行  
- 空值用 `IFNULL`/`COALESCE`；分支逻辑用 `CASE`  
- 分组查询遵守「选中的非聚合列 ⊆ GROUP BY」

## 常见坑 / 面试点

- `COUNT(列)` 忽略该列的 `NULL`；`COUNT(*)` 计行数  
- `LENGTH` 按字节，`CHAR_LENGTH` 按字符（utf8mb4 下易踩坑）  
- 在 `WHERE` 对列套函数可能影响索引；可改为对常量做变换  
- MySQL 8 默认 `ONLY_FULL_GROUP_BY`，随意 `SELECT` 非分组列会报错
